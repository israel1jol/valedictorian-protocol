# The Valedictorian Protocol

A 24-week, self-paced curriculum for rebuilding high-school sciences (Chemistry, Physics, Biology) and English fluency from the ground up — benchmarked against AP exam standards and run like an interview-prep grind.

**Live site:** https://israel1jol.github.io/valedictorian-protocol/

## What it is

A single-page, fully self-contained study protocol:

- **Phase 1 — Chemistry** (Weeks 1–7)
- **Phase 2 — Physics** (Weeks 8–12)
- **Phase 3 — Biology** (Weeks 13–20)
- **Phase 4 — Synthesis** (Weeks 21–24)
- **English** runs as a daily parallel track across all 24 weeks

Each week has defined topics and a drill target. Each phase ends with a timed, released AP exam as the pass/fail gate. The core engine is a five-step daily loop: **Learn → Drill → Card → Teach → English.**

## Tech

- One static `index.html` — no build step, no dependencies, no framework
- Fonts via Google Fonts (Archivo, Atkinson Hyperlegible, JetBrains Mono)
- Responsive down to mobile, reduced-motion respected

## Run it locally

```bash

# open index.html in a browser
```
